# Requirements Document

## Introduction

The Resume Upgrade Wizard is a feature that allows candidates to improve their resume directly from the Resume Alignment Report page. When a candidate clicks "Upgrade Resume", they are taken to a dedicated wizard page where they can review AI-detected gaps, provide personal notes for each gap, select terminology improvements via checkboxes, add custom content, and ultimately generate and download an ATS-optimized PDF resume. The wizard leverages the existing `analyzer.py` pipeline (gap refinement, batch LLM calls, and PDF generation) and the existing backend endpoints (`/refine` and `/pdf`) to produce the upgraded resume.

After the candidate submits gaps and custom additions, the system calls the `/refine` endpoint in a single API call and presents each refined result (per gap and per custom addition item) with individual approve/reject controls. Only approved items are included in the final PDF. Additionally, any "About Me" text provided by the candidate is treated as professional summary content and merged into the Professional Summary section — not placed in additional sections. Any hyperlinks or URLs provided by the candidate in gap notes or custom additions are preserved as clickable links in the generated PDF.

## Glossary

- **Alignment Report**: The page at `/practice/[session_id]` that displays the resume match score, gaps, improvements, and other analysis results.
- **Resume Upgrade Wizard**: The new page at `/practice/[session_id]/upgrade` that guides the candidate through the resume improvement flow.
- **Gap**: A missing skill, experience, or qualification identified by the AI when comparing the resume to the Job Description.
- **Gap Note**: Free-text input provided by the candidate to address a specific gap (e.g., describing a project or experience that covers the gap).
- **Terminology Improvement**: A suggested keyword or phrasing change that aligns the resume's language more closely with the Job Description.
- **Custom Additions**: Free-text content the candidate wants to add to the resume (e.g., new certifications, education, or extra context).
- **Refined Gap Content**: The ATS-friendly paragraph generated by the LLM from a candidate's gap note, used to enrich the resume.
- **Refined Custom Item**: The ATS-friendly rewrite of a single custom addition line generated by the LLM.
- **Refinement Review Step**: The intermediate UI step shown after the `/refine` call returns, where the candidate approves or rejects each refined item before PDF generation.
- **About Me Content**: Free-text provided by the candidate describing themselves, which the system treats as professional summary material.
- **ATS-Optimized PDF**: The final downloadable resume PDF generated by the backend using `build_pdf_from_json` and `generate_ats_resume_json`.
- **Session**: A practice session record identified by `session_id`, stored in the `practice_sessions` database table.
- **Enhanced Analysis**: The JSON object stored in `practice_sessions.enhanced_analysis`, containing `gaps`, `improvements`, `match_score`, `ats_score`, and related fields.
- **Refine Endpoint**: `POST /api/v1/practice/session/{session_id}/refine` — accepts gap notes and custom additions, returns refined content per item.
- **PDF Endpoint**: `GET /api/v1/practice/session/{session_id}/pdf` — generates and returns the ATS-optimized PDF.
- **Template**: A named PDF layout style (e.g., "Classic ATS", "Modern Accent", "Two-Column Professional").

## Requirements

### Requirement 1

**User Story:** As a candidate, I want an "Upgrade Resume" button on the Alignment Report page, so that I can navigate to the resume improvement wizard without leaving the session context.

#### Acceptance Criteria

1. WHEN the session status is `ready_to_start`, THE Alignment Report page SHALL render an "Upgrade Resume" button in the top navigation bar alongside the existing "Start Interview" button.
2. WHEN the candidate clicks the "Upgrade Resume" button, THE system SHALL navigate the candidate to `/practice/[session_id]/upgrade`.
3. WHILE the session status is not `ready_to_start`, THE Alignment Report page SHALL hide the "Upgrade Resume" button.

---

### Requirement 2

**User Story:** As a candidate, I want to see all AI-detected gaps on the wizard page with a text input for each, so that I can provide context about my experience that addresses each gap.

#### Acceptance Criteria

1. WHEN the candidate navigates to `/practice/[session_id]/upgrade`, THE Resume Upgrade Wizard SHALL fetch the session's `enhanced_analysis` and display each gap as a labeled card.
2. WHEN the wizard renders a gap card, THE Resume Upgrade Wizard SHALL display the gap description text and a multi-line text input field for the candidate's notes.
3. WHILE the candidate has not entered any text in a gap note field, THE Resume Upgrade Wizard SHALL display a placeholder prompt (e.g., "Describe your experience or project that addresses this gap...").
4. IF the session has no gaps in `enhanced_analysis`, THEN THE Resume Upgrade Wizard SHALL display a message indicating no gaps were detected and skip the gaps section.

---

### Requirement 3

**User Story:** As a candidate, I want to see all terminology improvement suggestions as checkboxes, so that I can selectively approve which rewrites get applied to my resume.

#### Acceptance Criteria

1. WHEN the wizard renders the improvements section, THE Resume Upgrade Wizard SHALL display each improvement suggestion as a checkbox item with the suggestion text.
2. WHEN the candidate checks an improvement checkbox, THE Resume Upgrade Wizard SHALL mark that improvement as selected for inclusion in the refined resume.
3. WHEN the candidate unchecks an improvement checkbox, THE Resume Upgrade Wizard SHALL exclude that improvement from the refined resume.
4. WHILE the improvements list is empty, THE Resume Upgrade Wizard SHALL hide the improvements section entirely.

---

### Requirement 4

**User Story:** As a candidate, I want a free-text area to add custom content to my resume, so that I can include new certifications, education, or other information not captured in the original resume.

#### Acceptance Criteria

1. WHEN the wizard renders, THE Resume Upgrade Wizard SHALL display a "Custom Additions" text area below the gaps and improvements sections.
2. WHILE the candidate types in the custom additions field, THE Resume Upgrade Wizard SHALL preserve the input without clearing it on re-render.
3. IF the candidate prefixes a line with a section label (e.g., "certificate:", "education:"), THEN THE Resume Upgrade Wizard SHALL display a helper hint explaining that prefixed lines are placed in the correct resume section.
4. IF the candidate includes a line prefixed with "about me:" or writes content in an "About Me" style, THEN THE Resume Upgrade Wizard SHALL treat that content as professional summary material and pass it to the backend with a `about_me:` prefix so the LLM merges it into the Professional Summary section rather than placing it in additional sections.

---

### Requirement 5

**User Story:** As a candidate, I want the system to refine all my gap notes and custom additions in a single call and show me each result for review, so that I can approve or reject individual items before they are added to my resume.

#### Acceptance Criteria

1. WHEN the candidate clicks "Refine My Inputs", THE Resume Upgrade Wizard SHALL call `POST /api/v1/practice/session/{session_id}/refine` once with all gap notes, custom additions, and selected improvements in a single request.
2. WHILE the refine call is in progress, THE Resume Upgrade Wizard SHALL display a loading state and disable the refine button to prevent duplicate submissions.
3. WHEN the refine call succeeds, THE Resume Upgrade Wizard SHALL transition to a Refinement Review step that displays each refined gap paragraph and each refined custom addition item as a separate card.
4. WHEN the Refinement Review step renders, THE Resume Upgrade Wizard SHALL display an "Approve" button and a "Reject" button on each refined item card.
5. WHEN the candidate clicks "Approve" on a refined item, THE Resume Upgrade Wizard SHALL mark that item as approved and visually indicate the approved state.
6. WHEN the candidate clicks "Reject" on a refined item, THE Resume Upgrade Wizard SHALL mark that item as rejected and visually indicate the rejected state (e.g., dimmed or struck through).
7. WHILE no explicit action has been taken on a refined item, THE Resume Upgrade Wizard SHALL default the item to an approved state.
8. IF the refine endpoint returns an error, THEN THE Resume Upgrade Wizard SHALL display an inline error message and re-enable the refine button.

---

### Requirement 6

**User Story:** As a candidate, I want to generate my upgraded resume using only the approved refined items, so that the final PDF reflects exactly what I chose to include.

#### Acceptance Criteria

1. WHEN the candidate clicks "Generate Upgraded Resume" on the Refinement Review step, THE Resume Upgrade Wizard SHALL call `GET /api/v1/practice/session/{session_id}/pdf` with only the approved refined gap paragraphs and approved refined custom addition items.
2. WHEN the PDF is received, THE Resume Upgrade Wizard SHALL trigger a browser download of the PDF file named `improved-resume-{session_id}.pdf`.
3. WHILE the PDF generation is in progress, THE Resume Upgrade Wizard SHALL display a loading state and disable the generate button to prevent duplicate submissions.
4. IF the PDF endpoint returns an error, THEN THE Resume Upgrade Wizard SHALL display an inline error message and re-enable the generate button.
5. WHEN the candidate rejects all refined items, THE Resume Upgrade Wizard SHALL still allow PDF generation using only the selected terminology improvements and template.

---

### Requirement 7

**User Story:** As a candidate, I want any hyperlinks or URLs I provide in my gap notes or custom additions to appear as clickable links in the generated PDF, so that my resume preserves important references.

#### Acceptance Criteria

1. WHEN the candidate includes a URL or hyperlink in a gap note or custom addition, THE Resume Upgrade Wizard SHALL pass the raw text including the URL to the `/refine` endpoint without stripping or encoding the URL.
2. WHEN the LLM refines content containing a URL, THE Refine Endpoint SHALL preserve the URL in the refined output.
3. WHEN the PDF is generated, THE PDF Endpoint SHALL render any URL present in the accepted content as a clickable `<a href="...">` link in the PDF output, consistent with the existing hyperlink rule in the PDF generation prompt.

---

### Requirement 8

**User Story:** As a candidate, I want to choose a PDF template before generating my resume, so that I can select the visual style that best suits my needs.

#### Acceptance Criteria

1. WHEN the wizard renders, THE Resume Upgrade Wizard SHALL display a template selector with the options: "Classic ATS", "Modern Accent", and "Two-Column Professional".
2. WHEN the candidate selects a template, THE Resume Upgrade Wizard SHALL pass the selected template name as a query parameter to the PDF endpoint.
3. WHILE no template is explicitly selected, THE Resume Upgrade Wizard SHALL default to "Classic ATS".

---

### Requirement 9

**User Story:** As a candidate, I want the wizard page to match the existing dark-mode design system, so that the experience feels consistent with the rest of the application.

#### Acceptance Criteria

1. THE Resume Upgrade Wizard SHALL use the `bg-slate-900` background and `text-zinc-100` primary text color consistent with the existing design system.
2. THE Resume Upgrade Wizard SHALL use `bg-indigo-600` for primary action buttons, matching the existing button style.
3. WHEN the wizard renders on mobile viewports, THE Resume Upgrade Wizard SHALL stack all sections vertically and maintain readable font sizes.
